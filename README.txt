# Sage Eubanks — Portfolio

A static HTML/CSS/JS portfolio starter designed for a surreal, dreamlike photography site.

## Files
- index.html — page structure and your current work titles
- style.css — visual design, colors, typography, responsive layout
- script.js — mobile navigation and small interactions
- images/ — put your optimized photographs here

## Replace the placeholders
Search index.html for:
- `Add image`
- `YOUR-EMAIL-HERE`
- `YOUR-INSTAGRAM-URL`
- `Add your own artist statement...`
- `Add your education here.`
- `Add your exhibitions here.`

For each image placeholder, replace the `<div class="image-placeholder">...</div>` with:
`<img src="images/your-file.jpg" alt="Descriptive image title">`

Then add this CSS:
`.image-placeholder img { width:100%; height:100%; object-fit:cover; position:absolute; inset:0; }`

## Important
This version intentionally contains no invented artist statement, biography, CV entries, or generated photography. It uses the work titles currently visible on sageeubanks.com as the starting structure.
